一次离开，会发生什么

  1. 你在电脑前

    摄像头每秒只看两眼：画面里有没有人脸。不做身份识别，不录屏，不上传。

  2. 你起身离开

    连续 5 秒看不到人脸才算离开。低头看手机、转头说话都不会误触发。

  3. 第一帧就盖住

    先瞬间磨砂，再像折叠屏一样展开隐私面板。动画永远播放在已经遮住的画面上。

  4. 摄像头随即关闭

    没人需要看着空椅子。你离开多久，摄像头就省多久的电。

  5. 15 秒后转为纯黑

    实时磨砂会让系统持续计算模糊。没人看的时候，干脆变黑，连这部分也省下。

  6. 回来，按任意键

    一分钟内按任意键，面板折回成一道光；离开更久就要 Touch ID。陌生人随手一按？解不开。

我们也想诚实地告诉你。

遮罩不是锁屏

App 崩溃时遮罩会消失，其他程序也可能读取屏幕。离开久了，让它替你锁上 Mac。

普通摄像头不是 Face ID

RGB 摄像头无法证明活体。转头确认只是提高门槛，所以离开模式默认用 Touch ID 解锁。

只看得见镜头里的人

站在摄像头视野外的人看不到。坐在咖啡馆角落，更好的位置比任何算法都管用。

开源 · MIT

三行命令，装进你的 Mac。

# macOS 14+，Xcode 26+
git clone https://github.com/Functionhx/quietglass-plus.git && cd quietglass-plus
scripts/setup-isolated-signing.sh && bash build.sh "$PWD/dist/QuietGlass.app"
ditto dist/QuietGlass.app /Applications/QuietGlass.app && open -a QuietGlass

打开后：设置 → 保护 → 打开“摄像头自动保护”。默认就是“离开时遮挡，回来按键解锁”。
